# IQPR Time

نسخة نظيفة وجاهزة للنشر من منصة مواقيت الصلاة في العراق.

**الرابط الرسمي**: [iqpr-time.vercel.app](https://iqpr-time.vercel.app/)

- Next.js 15 + TypeScript
- واجهة عربية وإنجليزية
- 19 محافظة و121 مدينة
- Supabase كمصدر بيانات
- Swagger ومختبر API تفاعلي
- جاهزة للنشر على Vercel

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env.local` وأدخل قيم Supabase.
2. ثبّت الحزم: `npm install`
3. شغّل الموقع: `npm run dev`
4. افتح `http://localhost:3000`

تعليمات النشر الكاملة موجودة في [DEPLOYMENT.md](./DEPLOYMENT.md).
